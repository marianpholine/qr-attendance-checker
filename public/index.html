Attendance Management

QR Attendance System

Teacher Student

How the system works

  1. The teacher generates a unique QR code for a class or event.
  2. The student scans the QR code using the scanner page.
  3. The attendance is saved in the database as Present.
  4. The teacher can review the attendance list in real time.

Key features

  • No manual attendance entry
  • Teacher-controlled QR generation
  • Attendance stored in SQLite
  • Prevents duplicate check-ins
  • QR expires after a set time
